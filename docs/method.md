# 계산과 판단 근거

물리량 기호는 기울임꼴로, 단위와 구분용 첨자는 정체로 표기합니다. $C_{\mathrm{i}}$, $\varepsilon_{\mathrm{i}}$, $t_{\mathrm{i}}$의 i는 절연막을 구분합니다. $h\nu$의 $\nu$는 진동수를 나타내는 그리스 문자이며, 재료명 a-Si·a-IGZO와 단위 μm는 수식 변수와 구분합니다. [BIPM 표기 기준](https://www.bipm.org/en/publications/si-brochure/)

## 모델 조건과 구간 이동

MOBILITY 섹션 추출의 $V_{\mathrm{D}}$·$I_{\mathrm{D}}$를 $V_{\mathrm{GS}}$=$V_{\mathrm{DS}}$·$I_{\mathrm{DS}}$로 연결합니다. 각 후보의 피팅 $V_{\mathrm{th}}$를 대입해 $V_{\mathrm{GS}}-V_{\mathrm{th}}>0$, $V_{\mathrm{DS}}\ge V_{\mathrm{GS}}-V_{\mathrm{th}}$를 확인하고, 최소 오버드라이브와 포화 조건 여유를 표시합니다. p형은 전압과 $V_{\mathrm{th}}$의 극성을 바꾼 구동 좌표로 확인합니다. 이 검사는 사용한 포화식의 바이어스 일관성에 관한 것입니다. [MIT의 MOSFET 포화 영역 설명](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-spring-2009/resources/mit6_012s09_lec09/)

선택 구간의 시작·끝 전압을 함께 −0.5 / 0 / +0.5 V 옮겨 같은 폭으로 다시 회귀합니다. $\mu$는 $2a^2L/(C_{\mathrm{i}}W)$, $V_{\mathrm{th}}$는 $-b/a$로 계산합니다. $\Delta\mu=(\mu_{\mathrm{shift}}/\mu_{\mathrm{base}}-1)\times100\%$, $\Delta V_{\mathrm{th}}=V_{\mathrm{th,shift}}-V_{\mathrm{th,base}}$입니다. 원래 전압 축을 사용하므로 LTPS의 −0.5 V는 더 음의 방향입니다. 실제 범위를 완전히 덮지 못하거나 양의 구동 기울기가 없으면 해당 이동의 값을 제시하지 않습니다.

이 표의 세 행과 별도 후보 세 개는 서로 다른 비교입니다. 표는 한 구간의 선택 위치 민감도를, 후보 목록은 폭과 위치가 다른 구간들의 결과를 보여줍니다.

Tauc는 선택한 전이 모델로 변환한 뒤 양의 기울기·양의 $E_{\mathrm{g}}$·잔차·구간 앞뒤 기울기와 평활화 민감도를 점검합니다. $R^2$가 서로 다른 전이 모델을 공통 순위로 만드는 기준은 아닙니다. 박막 두께·반사 보정·전이 가정은 결과와 함께 표시합니다. [Tauc 방법의 적용 조건과 한계를 다룬 논문](https://doi.org/10.1002/adfm.202304523)

## 입력과 예제의 관계

실측 파일과 직접 올린 파일은 같은 분석 함수로 들어갑니다. 데모 이름으로 오류 여부를 정하지 않습니다. 열 구조·숫자·측정 간격을 실제로 검사합니다.

데모에서 제공하는 원본 겹치기는 오류를 넣기 전의 파일을 알고 있을 때만 가능합니다. 직접 올린 파일에서는 읽힌 수치와 검출 근거를 보여줍니다.

## TFT 포화 구간

MOBILITY 측정의 $V_{\mathrm{D}}$·$I_{\mathrm{D}}$를 사용합니다. 이 실험 구성의 동일 전압 조건을 분석용 $V_{\mathrm{GS}}$=$V_{\mathrm{DS}}$ 열로 옮겼습니다. 채널 폭 W와 길이 L은 파일별 조건을 따릅니다.

선택 구간에서 $\sqrt{|I_{\mathrm{DS}}|}=aV+b$를 피팅합니다.

- 문턱전압: $V_{\mathrm{th}}=-b/a$
- 포화 이동도: $\mu_{\mathrm{sat}}=2La^2/(WC_{\mathrm{i}})$
- 원본 계산의 $C_{\mathrm{i}}$: 1.75×10⁻⁸ F/cm²

실제 측정 범위에서 여러 구간을 탐색하고 적합도, 정규화 잔차, 앞뒤 기울기 변화와 인접 구간의 결과 변화를 계산합니다. 현재 기준은 $R^2$ ≥ 0.995, 정규화 잔차 ≤ 0.02, 기울기 변화 ≤ 0.20, 이동도 변화 ≤ 15%, 문턱전압 변화 ≤ 0.5 V입니다. 기준을 만족하는지와 구간 폭, 품질 점수를 순서대로 사용합니다.

이 값들은 현재 자료를 검토하는 규칙으로 정했습니다. $R^2$는 직선 모양, 잔차는 직선 주변의 흩어짐, 기울기·구간 이동은 선택 위치에 따른 변화를 확인하는 역할입니다. 코드의 기준과 화면의 근거 숫자를 함께 공개합니다.

## 비슷한 후보를 어떻게 읽나

기본 표시 구간은 계산 규칙에서 앞선 후보입니다. 화면 옆의 범위는 표시된 후보들의 이동도·문턱전압 최솟값과 최댓값입니다. 구간 선택에 따른 변화이며 통계적 신뢰구간은 아닙니다.

예를 들어 IGZO W20/L4에서는 비슷한 적합도의 인접 구간에서도 이동도가 약 7.44~8.76 cm²/(V·s), 문턱전압이 약 2.441~2.834 V로 달라집니다. 값 하나와 함께 이 변화를 읽도록 구성했습니다.

기본 5.50~9.50 V 구간은 $\mu$ 약 8.07, $V_{\mathrm{th}}$ 약 2.631 V입니다. 5.00~9.00 V로 옮기면 $\mu$ 약 7.44, $V_{\mathrm{th}}$ 약 2.441 V로 바뀝니다. 두 구간의 표시 $R^2$는 모두 0.9982지만, 기울기의 제곱으로 계산하는 $\mu$는 약 7.8% 달라집니다. 화면은 이 차이와 선택한 구간의 그래프를 연결합니다.

원본 CSV에는 signed $I_{\mathrm{DS}}$를 남깁니다. $\sqrt{|I_{\mathrm{DS}}|}$는 피팅을 위한 변환값이며 원본 전류를 덮어쓰지 않습니다. 섹션형 DAT·CSV에서는 MOBILITY의 필수 전압·전류 셀만 이 분석의 행 검사에 사용합니다. 사용하지 않는 보조 열의 문자가 정상 $V_{\mathrm{D}}$·$I_{\mathrm{D}}$ 행을 삭제하지 않습니다.

## 곡선 점검

전류 튐은 $\sqrt{|I_{\mathrm{DS}}|}$에서 앞뒤 변화가 전체 범위의 25% 이상이고 방향이 반전되는 점을 찾습니다. 측정 간격 점검은 전압 간격 중앙값의 5배를 넘는 간격을 찾습니다.

검출은 검토 위치를 정하는 규칙입니다. 원인 판단에는 원본 파일과 측정 기록이 필요합니다. 실제 수치를 자동 삭제하거나 누락 구간을 보간하지 않습니다.

## Tauc

파장 λ에서 광자 에너지를 E = 1239.841984/λ로 계산합니다. 투과율과 재료 프로파일의 두께·전이 모델·굴절률로 Tauc 변환을 만든 뒤 직선 구간을 피팅합니다. $E_{\mathrm{g}}$는 선택 직선의 에너지축 절편입니다.


### 변환 수식

측정한 파장과 투과율에서 다음 순서로 계산합니다.

1. 투과율을 비율로 변환합니다: $T=T_{\%}/100$.
2. 파장을 광자 에너지로 바꿉니다: $E=h\nu=1239.841984/\lambda$. 파장은 nm, 에너지는 eV입니다.
3. 투과율 기반 근사는 $\alpha_{\mathrm{BL}}=-\ln(T)/d$입니다. 두께는 $d=d_{\mathrm{nm}}\times10^{-7}$ cm로 변환해 흡수계수를 $\mathrm{cm}^{-1}$로 구합니다.
4. Tauc 세로축은 $Y=(\alpha E)^p$입니다. 직접 허용 전이는 $p=2$, 간접 허용 전이와 기존 비정질 설정은 $p=1/2$입니다. 같은 지수를 쓰더라도 모델 이름은 구분합니다.
5. 선택 구간의 직선 $Y=mE+b$에서 $E_{\mathrm{g}}=-b/m$을 구합니다.

<details>
<summary>단순 반사 보정 모델의 흡수계수</summary>

계면 반사율은 $R_{af}=[(n_a-n_f)/(n_a+n_f)]^2$, $R_{fg}=[(n_f-n_g)/(n_f+n_g)]^2$로 계산합니다. 여기서 $a$, $f$, $g$는 각각 공기·박막·유리 조건을 구분합니다.

$A=(1-R_{af})(1-R_{fg})$, $B=R_{af}R_{fg}$로 놓으면 구현된 정방향 모델은 $T=Ax/(1-Bx^2)$입니다.

이를 역산한 $x=2T/[A+\sqrt{A^2+4BT^2}]$에서 $\alpha=-\ln(x)/d$를 계산합니다. 상수 굴절률을 사용하는 단순 계면 반사 모델이며, 투과율 기반 근사와 별도의 후보로 표시합니다.

투과율 기반 모델과 단순화한 반사 보정 모델을 구분합니다. 후보 비교에서는 전이 모델과 흡수계수 조건을 함께 표시합니다. Tauc 그래프의 점은 표시용으로 줄이지만 피팅은 원본 분석 모듈에서 전체 측정점을 사용합니다.

직접 올린 파일은 해당 재료의 고정 실험 프로파일을 적용할지 먼저 확인합니다. a-Si·Poly-Si·a-IGZO의 박막 굴절률은 각각 4.045·3.715·1.92이며, air 기준선·glass 기판 조건입니다. 다른 조건을 선언한 입력은 계산을 보류합니다. 후보는 모델 조합별 순서로 보여주며 서로 다른 물리 모델의 $R^2$를 통합 순위로 사용하지 않습니다.

## 입력과 계산량 제한

파일은 3 MB·20,000행 이하를 읽습니다. TFT 포화 곡선은 5,000점 이하, 전압 ±1,000 V·전체 범위 200 V 이하, 전류 ±1 A를 지원합니다. 후보 시작점 수와 측정점 수의 곱은 극성별 2백만 이하로 제한합니다. 제한을 넘거나 필수 셀을 읽지 못하면 원파일 확인으로 안내하고 계산을 보류합니다.

UV–Vis는 헤더와 실제 숫자행의 수를 비교합니다. 앞뒤뿐 아니라 내부 파장 누락도 표시합니다. JASCO의 확장 정보 표지 이후는 장비 메타데이터로 구분합니다.

공개판은 원자료 숫자 대조, 독립 회귀, 정상·오류 입력, 실제 브라우저 조작으로 확인합니다. 수동 선택 대비 파라미터 정확도나 참값과의 오차는 별도 비교 실험이 필요합니다. [현재와 과거 검증 기록](../VALIDATION.md)
