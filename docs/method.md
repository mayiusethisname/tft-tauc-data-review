# 계산과 판단 근거

## 입력과 예제의 관계

실측 파일과 직접 올린 파일은 같은 분석 함수로 들어갑니다. 데모 이름으로 오류 여부를 정하지 않습니다. 열 구조·숫자·측정 간격을 실제로 검사합니다.

데모에서 제공하는 원본 겹치기는 오류를 넣기 전의 파일을 알고 있을 때만 가능합니다. 직접 올린 파일에서는 읽힌 수치와 검출 근거를 보여줍니다.

## TFT 포화 구간

MOBILITY 측정의 VD·ID를 사용합니다. 이 실험 구성의 동일 전압 조건을 분석용 VGS=VDS 열로 옮겼습니다. 채널 폭 W와 길이 L은 파일별 조건을 따릅니다.

선택 구간에서 √|IDS| = a·V + b를 피팅합니다.

- 문턱전압: Vth = −b/a
- 포화 이동도: μ = 2·L·a² / (W·Ci)
- 원본 계산의 Ci: 1.75×10⁻⁸ F/cm²

실제 측정 범위에서 여러 구간을 탐색하고 적합도, 정규화 잔차, 앞뒤 기울기 변화와 인접 구간의 결과 변화를 계산합니다. 현재 기준은 R² ≥ 0.995, 정규화 잔차 ≤ 0.02, 기울기 변화 ≤ 0.20, 이동도 변화 ≤ 15%, 문턱전압 변화 ≤ 0.5 V입니다. 기준을 만족하는지와 구간 폭, 품질 점수를 순서대로 사용합니다.

이 값들은 현재 자료를 검토하는 규칙으로 정했습니다. R²는 직선 모양, 잔차는 직선 주변의 흩어짐, 기울기·구간 이동은 선택 위치에 따른 변화를 확인하는 역할입니다. 코드의 기준과 화면의 근거 숫자를 함께 공개합니다.

## 비슷한 후보를 어떻게 읽나

기본 표시 구간은 계산 규칙에서 앞선 후보입니다. 화면 옆의 범위는 표시된 후보들의 이동도·문턱전압 최솟값과 최댓값입니다. 구간 선택에 따른 변화이며 통계적 신뢰구간은 아닙니다.

예를 들어 IGZO W20/L4에서는 비슷한 적합도의 인접 구간에서도 이동도가 약 7.44~8.76 cm²/(V·s), 문턱전압이 약 2.441~2.834 V로 달라집니다. 값 하나와 함께 이 변화를 읽도록 구성했습니다.

기본 5.50~9.50 V 구간은 μ 약 8.07, Vth 약 2.631 V입니다. 5.00~9.00 V로 옮기면 μ 약 7.44, Vth 약 2.441 V로 바뀝니다. 두 구간의 표시 R²는 모두 0.9982지만, 기울기의 제곱으로 계산하는 μ는 약 7.8% 달라집니다. 화면은 이 차이와 선택한 구간의 그래프를 연결합니다.

원본 CSV에는 signed IDS를 남깁니다. √|IDS|는 피팅을 위한 변환값이며 원본 전류를 덮어쓰지 않습니다. 섹션형 DAT·CSV에서는 MOBILITY의 필수 전압·전류 셀만 이 분석의 행 검사에 사용합니다. 사용하지 않는 보조 열의 문자가 정상 VD·ID 행을 삭제하지 않습니다.

## 곡선 점검

전류 튐은 √|IDS|에서 앞뒤 변화가 전체 범위의 25% 이상이고 방향이 반전되는 점을 찾습니다. 측정 간격 점검은 전압 간격 중앙값의 5배를 넘는 간격을 찾습니다.

검출은 검토 위치를 정하는 규칙입니다. 원인 판단에는 원본 파일과 측정 기록이 필요합니다. 실제 수치를 자동 삭제하거나 누락 구간을 보간하지 않습니다.

## Tauc

파장 λ에서 광자 에너지를 E = 1239.841984/λ로 계산합니다. 투과율과 재료 프로파일의 두께·전이 모델·굴절률로 Tauc 변환을 만든 뒤 직선 구간을 피팅합니다. Eg는 선택 직선의 에너지축 절편입니다.

| 재료 | 원본 프로파일 두께 | 전이 설정 |
| --- | ---: | --- |
| a-Si | 50 nm | 간접 허용 전이 |
| Poly-Si | 50 nm | 간접 허용 전이 |
| a-IGZO | 40 nm | 기존 비정질 설정 · 직접 허용 전이 |

투과율 기반 모델과 단순화한 반사 보정 모델을 구분합니다. 후보 비교에서는 전이 모델과 흡수계수 조건을 함께 표시합니다. Tauc 그래프의 점은 표시용으로 줄이지만 피팅은 원본 분석 모듈에서 전체 측정점을 사용합니다.

직접 올린 파일은 해당 재료의 고정 실험 프로파일을 적용할지 먼저 확인합니다. a-Si·Poly-Si·a-IGZO의 박막 굴절률은 각각 4.045·3.715·1.92이며, air 기준선·glass 기판 조건입니다. 다른 조건을 선언한 입력은 계산을 보류합니다. 후보는 모델 조합별 순서로 보여주며 서로 다른 물리 모델의 R²를 통합 순위로 사용하지 않습니다.

## 입력과 계산량 제한

파일은 3 MB·20,000행 이하를 읽습니다. TFT 포화 곡선은 5,000점 이하, 전압 ±1,000 V·전체 범위 200 V 이하, 전류 ±1 A를 지원합니다. 후보 시작점 수와 측정점 수의 곱은 극성별 2백만 이하로 제한합니다. 제한을 넘거나 필수 셀을 읽지 못하면 원파일 확인으로 안내하고 계산을 보류합니다.

UV–Vis는 헤더와 실제 숫자행의 수를 비교합니다. 앞뒤뿐 아니라 내부 파장 누락도 표시합니다. JASCO의 확장 정보 표지 이후는 장비 메타데이터로 구분합니다.

## 확인한 범위

공개판은 원자료 숫자 대조, 독립 회귀, 정상·오류 입력, 실제 브라우저 조작으로 확인합니다. 수동 선택 대비 파라미터 정확도나 참값과의 오차는 별도 비교 실험이 필요합니다. [현재와 과거 검증 기록](../VALIDATION.md)
