# 화면 사용법

## 1. 물질과 실측 파일 고르기

TFT 또는 Tauc를 고르고, 바로 아래에서 물질을 선택합니다. 물질명 옆의 작은 **i**에 커서를 올리면 재료 설명이 나타납니다. 모바일에서는 눌러서 읽고 바깥을 누르면 닫을 수 있습니다.

TFT 파일은 물질마다 세 개입니다. 예를 들어 `IGZO2004.csv`의 소자 크기는 **W20/L4 μm**입니다. W는 채널 폭, L은 채널 길이입니다. 크기 옆 도움말에 간단한 그림과 해당 파일의 치수를 넣었습니다. 파일명 규칙은 이 실험 자료에 적용되는 규칙입니다.

UV–Vis는 물질마다 원본 스펙트럼 한 개를 제공합니다.

**이 파일 분석하기**는 현재 화면에서 분석을 시작합니다. **CSV 내려받기**는 같은 파일을 컴퓨터에 저장합니다.

## 2. 대표 구간과 결과 변화 읽기

TFT를 열면 기본 표시 구간과 이동도·문턱전압이 나옵니다. 옆의 **주변 구간을 함께 계산하면**에서 다른 후보 구간으로 옮겼을 때 계산값이 어디까지 바뀌는지 볼 수 있습니다.

자세히 살펴보고 싶으면 **다른 구간과 비교하기**를 펼칩니다. 후보를 누르면 그래프, 계산값, 근거가 함께 바뀝니다. 비슷하게 겹치는 후보를 반드시 하나씩 선택할 필요는 없습니다.

후보 옆의 **기본 구간 대비 μ·Vth 차이**로 바뀐 크기를 먼저 읽고, **선택한 구간 그래프 보기**로 곡선을 확인합니다. 후보를 바꿔도 확대 범위를 유지하며 키보드로 연속해서 선택할 수 있습니다.

근거 버튼에서는 직선 적합도, 잔차와 기울기, 구간 이동, 측정점과 범위를 볼 수 있습니다. 용어 옆 i는 뜻을 짧게 설명합니다.

Tauc에서는 **Tauc 변환과 피팅**과 **원본 투과율**을 오갑니다. 모델별 후보 비교를 펼칠 때는 전이 모델과 흡수계수 계산 조건을 함께 확인합니다.

현재 전이 모델·흡수계수 계산법·두께·굴절률·기준선·기판은 대표 Eg 아래에도 표시합니다.

## 3. 그래프 조작하기

- **＋ 확대 / － 축소** 또는 마우스 휠로 확대·축소합니다.
- 그래프를 드래그하면 위치를 옮길 수 있습니다.
- **전체 보기**, 두 번 누르기 또는 그래프에 초점을 둔 상태의 0 키로 처음 범위에 돌아옵니다.
- 커서를 올리면 가까운 측정값을 아래에서 읽을 수 있습니다.

## 4. 문제가 있는 파일 살펴보기

실측 파일 아래 **문제가 있는 파일도 살펴볼까요?**를 펼칩니다.

확인 의견의 **이 위치 확대**를 누르면 그래프가 해당 범위로 이동합니다. 해칭한 영역은 확인할 위치이고, 빨간 원은 검출한 점입니다. **대조 원본 겹쳐 보기**는 오류를 넣기 전의 실제 파일을 점선으로 보여줍니다.

전류 열 이름이 없는 경우에는 열 이름 표와 단위가 미확정인 원본 숫자를 보여줍니다. **열 이름이 있는 원본 열기**로 올바른 입력과 비교할 수 있습니다. 이 단계에서는 이동도·문턱전압을 계산하지 않습니다.

확인 절차는 **위치 확인 → 원자료 대조 → 수정한 파일로 다시 분석**입니다. [오류별 자세한 설명](cases.md)

## 5. 내 파일 넣기와 취소

**내 파일로 분석하기**를 펼쳐 DAT·CSV를 선택합니다. 알려진 TFT 파일명에서 재료와 W/L을 읽어 입력란에 제안합니다. 측정 기록과 맞는지 확인하고 **파일의 측정 조건이 위 내용과 맞는지 확인했어요**에 체크한 뒤 분석합니다. 입력을 고치거나 파일을 바꾸면 다시 확인합니다.

파일명과 다른 조건을 쓰려면 표시된 차이를 읽고 그 변경을 확인합니다. DAT는 MOBILITY 포화 측정을 분석합니다. 광학 파일은 표시된 두께·굴절률·air 기준선·glass 기판과 같은 실험 조건의 JASCO 투과율 형식을 사용합니다.

- **선택 취소**: 선택한 파일과 분석 화면을 비웁니다.
- **분석 취소**: 진행 중인 요청을 취소하고 파일을 내려놓습니다.
- 새 파일은 같은 이름이어도 내용이 바뀌면 다른 검토 기록으로 다룹니다.

오류 의견에서 **수정한 파일 넣기**를 누르면 업로드 영역으로 돌아갑니다.

## 6. 검토 기록 남기기

선택한 후보와 메모를 **이 구간 사용** 또는 **검토 보류**로 기록합니다. 입력 확인을 통과하지 못한 파일은 사용으로 기록할 수 없습니다.

기록은 현재 브라우저에 저장됩니다. **검토 기록 내려받기**에는 후보와 메모를 담고 원본 파일 내용은 담지 않습니다. 데이터 전송과 저장에 관한 설명은 화면 맨 아래에서 볼 수 있습니다.

후보나 메모를 바꾸면 **변경한 내용이 아직 기록되지 않았어요**가 표시됩니다. 사용·보류 버튼으로 다시 기록하거나 **마지막 기록으로 돌아가기**로 저장된 선택을 불러옵니다. 내려받는 기록에는 실제 계산 조건도 들어갑니다.
