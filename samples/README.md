# 예제 데이터

원본 실험자료의 숫자를 발췌했습니다. TFT는 물질별 세 파일, UV–Vis는 물질별 한 파일입니다.

| 종류 | 물질 | 원자료 | 선택한 조건 |
| --- | --- | --- | --- |
| TFT | a-Si | aSi2002.DAT · aSi2006.DAT · aSi2020.DAT | W20/L2 · W20/L6 · W20/L20 μm |
| TFT | a-IGZO | IGZO2002.csv · IGZO2004.csv · IGZO2010.csv | W20/L2 · W20/L4 · W20/L10 μm |
| TFT | LTPS | LTPS1002.DAT · LTPS1005.DAT · LTPS1010.DAT | W10/L2 · W10/L5 · W10/L10 μm |
| UV–Vis | a-Si | a-Si.csv | 300~700 nm, 4,001점 |
| UV–Vis | a-IGZO | a-IGZO.csv | 300~700 nm, 4,001점 |
| UV–Vis | Poly-Si | poly-Si.csv | 300~700 nm, 4,001점 |

## 정리한 내용

TFT는 각 파일의 MOBILITY 섹션 201점을 가져왔습니다. 원본의 $V_{\mathrm{D}}$·$I_{\mathrm{D}}$를 $V_{\mathrm{GS}}$=$V_{\mathrm{DS}}$·$I_{\mathrm{DS}}$ 열로 연결하고 CSV로 정리했습니다. 음전압과 전류를 포함한 측정 숫자는 바꾸지 않았습니다.

광학 자료는 파장·투과율 4,001쌍과 700→300 nm 측정 순서를 유지했습니다. 기기·축·측정 범위를 읽는 데 필요한 헤더를 남기고 날짜·사용자 메타데이터는 제외했습니다.

3.1에서 총 12개 파일, 측정점 13,812개을 원자료와 직접 비교했습니다. TFT의 음수 전류 664개를 부호까지 보존합니다. [파일별 원본·발췌본 해시와 대조 내역](manifest.json)

대조에는 분석 모듈을 불러오지 않는 [출처 확인 도구](../tools/verify_sources.py)를 사용합니다. 원본의 MOBILITY·XYDATA와 공개 CSV를 직접 읽어 순서·점 수·숫자를 비교합니다. TFT 그래프와 회귀에서 쓰는 √|$I_{\mathrm{DS}}$| 변환은 이 검사와 분리했습니다.

3.0의 TFT 발췌본에는 전류를 절댓값으로 옮긴 오류가 있었습니다. 3.1에서 signed $I_{\mathrm{D}}$를 복원하고 원자료 대조를 수정했습니다. [변경 내역](../CHANGELOG.md)

TFT의 세 파일은 채널 크기가 다른 소자입니다. 같은 조건을 세 번 반복 측정한 자료로 묶지 않습니다.

## 오류 예제

오류 파일은 `examples.py`가 실측 복사본에서 생성합니다. 다운로드한 오류 CSV를 직접 올려도 같은 진단을 거칩니다.

| 오류 | 바꾼 부분 | 화면에서 볼 내용 |
| --- | --- | --- |
| 전류 튐 | 중앙 전류 1점 → 원본 최대 절댓값의 15배 | 빨간 점, 위치 확대, 원본 겹치기 |
| 중간 행 누락 | 연속된 11개 측정점 삭제 | 벌어진 간격, 해칭 영역, 연결되지 않은 곡선 |
| 열 이름 누락 | $I_{\mathrm{DS}}$ → UNKNOWN | 열 이름 표, 단위 미확정 숫자 그래프 |
| 광학 범위 잘림 | 헤더는 두고 300~380 nm의 801점만 유지 | 실제 범위와 비어 있는 영역 |
| 투과율 범위 초과 | 400 nm 한 점 → 120% | 100% 기준선과 범위 밖 측정점 |

TFT 오류는 세 물질에 각 5개, 광학 오류는 세 물질에 각 2개로 총 21개입니다. 각 예제의 원본과 수정 내용은 분석 화면의 자료·조건 항목에서도 볼 수 있습니다.

3.2의 파일 표시·다운로드 이름은 `aIGZO_W20_L04_Mobility.csv` 형식입니다. `MOBILITY`는 원본 섹션 이름이며 $V_{\mathrm{GS}}$=$V_{\mathrm{DS}}$로 연결한 측정을 뜻합니다. 저장소의 발췌본 이름과 수치는 유지했습니다.

전류 단차 예제는 구동 범위 60% 이후 전류에 원본 최대 절댓값의 20%를 같은 부호로 더합니다. 고전압 감쇠 예제는 65% 이후 전류에 1에서 0.15까지 감소하는 계수를 곱합니다. 바뀐 전류를 그대로 그리고, 원본과 겹쳐 비교할 수 있습니다.
